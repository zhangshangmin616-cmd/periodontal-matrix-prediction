# Author-processed expression in the Wuhan human periodontal ligament stem cell series

Wuhan University's GSE312900 series profiles continuous tension for 24 or 48 hours in cultured human PDLSCs. Earlier project searches had recorded its design but had never scored its expression. GEO lists no associated publication in the downloaded series metadata. The depositor identifies 18 libraries, with a non-targeting sh-control and a PIEZO1-knockdown arm. The three sh-control libraries per time were scored. A single 0-hour sh-control group supplies both contrasts. A time-matched unloaded group and a donor-to-library mapping are unavailable. The 24- and 48-hour results therefore reflect time under the culture protocol together with loading. [GEO series](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE312900) · [Public BioProject](https://www.ebi.ac.uk/ena/browser/view/PRJNA1377575)

The worksheet contains 23,314 feature rows. Unique exact matches cover 10,554 of the 10,806-benchmark background, including every one of the 101 targets. The 252 unmatched background genes were omitted. GEO library descriptions directly identify the worksheet column corresponding to each sample. ENA records 21 technical runs for 18 libraries. Nine sh-control libraries have 12 technical runs in total. The FPKM table has one column per library. Counting technical runs as independent observations would inflate the sample size. [GEO workbook](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE312nnn/GSE312900/suppl/GSE312900_fpkm.xlsx) · [GEO sample metadata](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE312nnn/GSE312900/miniml/GSE312900_family.xml.tgz)

Units are percentile points. Six single-library deletions at each duration retained the direction of both comparisons. These checks describe the measured libraries. Gene-length normalisation in FPKM changes gene order relative to counts. The companion NCBI-count analysis tests the original common-background ranking. The two processing pipelines reuse the same specimens.

Run `python stage17/culture/score.py` and `python stage17/culture/check.py` from the extracted archive with Python, NumPy and openpyxl. `score.py` recreates the sample crosswalk, coverage, scores, deletion estimates and gene-level predictions. `check.py` rechecks the publisher of each measurement at the GEO sample-record level, the source workbook's SHA-256, and all scores using separate rank and absolute-error calculations. Source download links are in `fetch.py`, with local names `fpkm.xlsx`, `geo_matrix.txt.gz` and `family.xml.tgz`. ENA's `ena_runs.json` is the [read-run manifest](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=PRJNA1377575&result=read_run&fields=run_accession,experiment_accession,sample_accession,study_accession,scientific_name,experiment_title,library_strategy,fastq_md5&format=json).
