Set before scoring GSE189288 on 25 November 2026. This study compared naturally occluding and non-contacting premolars in patients visiting Yonsei. More physiological loading is represented by contact minus hypofunction. The hypofunction group provides a baseline, not a pre-treatment observation. Apply the original day-7, equal pressure/tension, within-cell-group, fixed-RNA-share atlas model in that direction, retaining all 101 original genes and the original 10,806 genes for ranking. Also report the pooled group-contrast scores when participants can be reconstructed, and sensitivity to deleting each inferential unit. No gene, direction, response scale or magnitude will be selected according to the results. This is a secondary cross-context analysis of different occlusal states, not a trial of a force appliance or temporal change. An actual biological or technical overlap with previously used data changes its evidentiary classification and must be reported.
