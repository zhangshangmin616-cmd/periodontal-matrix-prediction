# Technical control using held-out cells

Analysis rule recorded before computing split-cell forecasts. Use all 62,490 analysis barcodes of GSE327337 and the existing six cell-group labels. Within each library and group, sort on SHA-256 of the UTF-8 string 'PDL-holdout-v1|library|barcode', then distribute in round-robin order to four blocks. Evaluate all six ordered choices of two training blocks versus the two complementary test blocks. Keep all groups, including the smallest (39 glial cells in PP3D). Blocks are repeated partitions of the same five libraries, rather than patient replicates. Prior clinical and atlas results have already been examined.

For each side and each time (days 3 and 7), compute independent class CPM profiles in the two halves. The control library in each half defines its own control profiles and captured RNA shares. Generate four held-out synthetic tissue changes from the test half: (a) neither profiles nor shares change, (b) only the five named profiles are replaced with the held-out loaded profiles, (c) only the shares change to the held-out load shares, and (d) both change. The held-out control profile always supplies the residual group. These interventions describe what was varied in a constructed mixture. They give no independent biological evidence about which component changed in a patient.

Forecast each setting from the same held-out untreated tissue abundance, giving the predictor the true baseline shares of that artificial mixture. Estimate broad-group RNA-state multipliers from training-half cells. For share transfer, multiply the held-out control shares by the training-half loaded/control share ratios and renormalize. Never expose the predictor to held-out loaded profiles or held-out loaded shares. Compare no response, state only, shares only, and both. A further state-only control transfers the other side at the same time. Use the existing transfer rule, predicted post = observed test baseline × (1 + modelled post)/(1 + modelled baseline), all amounts in CPM. Report log2(CPM+1) change as a secondary endpoint. Evaluate both mean absolute percentile-rank error across the frozen 101 matrix genes and absolute error in the mean of their ranks. Ranks use the fixed 10,806-gene background. Round CPM to 10 decimals for rank ties to avoid artificial splits from floating-point operations. Give all four side/time conditions equal weight, and average over six allocations for technical stability. Differences across splits do not yield population confidence intervals. Do not change parameters or the gene set after reading results.
