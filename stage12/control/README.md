# Testing predictions on held-out cell mixtures

We used a split-cell technical control to establish whether the fixed model can detect a known change under its own mixture assumptions. The 62,490 QC-passing barcodes of GSE327337 were assigned, within library and existing cell group, to four balanced, deterministic blocks. This produced 120 blocks across five libraries and six cell groups. Splitting the smallest group, 39 day-3 pressure glial cells, leaves 19 or 20 cells in each half. The six possible ordered two-block training sets each had two mutually exclusive test blocks. All contrasts were constructed from cells that the corresponding predictor had not seen. All six splits reuse the same five libraries and the numbers below are technical averages. [Atlas](https://doi.org/10.1177/00220345261491310) · [Source matrices](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE327337)

The synthetic untreated tissue is a weighted sum of the test-half control group profiles. The synthetic loaded tissue uses the same test-half control groups and weights except for the profiles or weights deliberately changed in that scenario. In the state-only scenario, for instance, the five named groups use the test-half profiles from the relevant loaded library. The test-half residual profile and baseline RNA weights remain fixed. The predictor receives the exact baseline weights by design, mirroring the clinical stage after weight estimation and isolating the transfer step. Its state and share change factors come exclusively from training cells. It receives neither the loaded profiles nor the loaded weights used to construct the test outcome. The same marker definitions, library setting and capture effects are shared by both halves. The same test baseline contributes to each constructed contrast. This design establishes recovery under the chosen mixing rule. It cannot identify the biological source of a change in a clinical biopsy.

### Mean absolute error across the 101 individual gene percentile changes

| Change imposed on test cells | Zero | State forecast | RNA-share forecast | Joint forecast | State from opposite side |
|---|---:|---:|---:|---:|---:|
| Neither | 0.000 | 3.629 | 3.082 | 5.293 | 3.629 |
| Named-group expression only | 3.867 | 2.254 | 4.511 | 3.726 | 4.079 |
| RNA shares only | 3.221 | 4.380 | 0.850 | 3.734 | 4.632 |
| Both | 5.601 | 3.850 | 3.996 | 2.044 | 5.294 |

When the construction changed only the five named profiles, the matched state forecast beat zero for individual-gene rank error in 24/24 side/time-by-split comparisons and placed first among the five forecasting rules in 22/24. For the aggregate panel score the same matched forecast beat zero in 9/24 comparisons. Across four side/time conditions and six allocations, aggregate error was 0.413 points for the matched forecast and 0.309 for zero. The expression-level log₂(CPM + 1) gene MAE was 0.154 for the state forecast and 0.284 for zero. Under share-only and joint changes the generating model had the smallest individual-gene rank MAE in 24/24 comparisons. The zero error in the no-change scenario follows from construction.

### Numerical reproduction

From this directory run `python score.py` and `python check.py` with NumPy. The public-data companion, `block_counts.npz`, contains integer counts for the fixed genes along with full-feature UMI denominators for each of the 120 library-by-cell-group blocks. The checker verifies all 62,490 assignments from their barcodes and independently evaluates all 480 split-specific predictions. Two implementations differed by at most 3.56 × 10⁻¹⁵ in the final metrics. Group totals and depths reassembled from the blocks agree exactly with the original frozen counts. Machine-readable outputs give the results by side, time and split. Gene and panel rank errors are in percentile points. Log-expression errors are in log₂(CPM + 1).

To reproduce the block input from the unmodified public data, place the five sets of three GEO files (features, barcodes and Matrix Market counts) in one directory, and run `python build_blocks.py --raw PATH --features PATH_TO_stage5/reference/features.tsv --check-raw PATH_TO_stage4/inputs_manifest.tsv`. This step additionally needs SciPy. It consumes the included barcode and group assignments in `heldout_assignments.tsv.gz`, whose block identifiers are independently re-derived in `check.py`. To verify the sums against the earlier archived whole-group counts, add `--historical PATH_TO_stage10/reference_counts.npz`. To regenerate the saved membership from the earlier barcode quality/marker flags, use `--new-membership-from PATH_TO_stage4/results`. We rebuilt all block inputs from the original Matrix Market files in a clean directory and checked every element against the compact inputs.
