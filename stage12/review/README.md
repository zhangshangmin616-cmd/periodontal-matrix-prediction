# How much information comes from assigning changes to individual genes?

The state-only model assigns a different shift in expression rank to each of the 101 genes. We kept each sample or participant's mean forecast fixed and asked whether those different shifts reduced individual-gene absolute error. A common value assigned to every panel gene gives exactly the original aggregate prediction while removing all between-gene variation. As a second control, permuting the predicted changes among the genes preserves their mean and full distribution, but changes which gene receives which prediction. The main permutation matches deciles of expression in the untreated single-cell atlas. We used the same label reassignment across all 13 units, summarising Seoul with equal weight per participant and the two Leuven group contrasts separately. Fractions of random reassignments are descriptive comparisons across gene identities.

| Unit | Zero change | Uniform panel mean | Actual gene assignment | Expected permuted assignment, expression matched |
|---|---:|---:|---:|---:|
| Seoul, three weeks | 5.554 | 5.558 | 6.249 | 6.488 |
| Leuven, day 7 | 6.173 | 6.153 | 6.536 | 6.917 |
| Leuven, day 28 | 2.511 | 2.641 | 3.299 | 3.770 |

Values are mean absolute errors in rank percentile points. All nonzero columns produce the same aggregate prediction in each study unit. The assigned gene labels carry information relative to these alternative pairings, while giving every gene its group’s predicted panel mean is more accurate in all three comparisons. Conditional randomisation does not match expression covariance, variability, dynamic range or other biological relationships. A uniform shift is defined on the scored panel, without simulating a complete 10,806-gene ranking or a biological cell state.

Python 3.10+ and NumPy suffice. Use `python stage12/review/identity.py` and `python stage12/review/check_identity.py` from the archive root. The sole numerical input is stage11/specificity/rank_changes.npz. The expected reassignment error is computed analytically; the retained quantiles and counts are from 10,000 Monte Carlo permutations per control. All numerical indicators are retrospective.

## Range and matching sensitivity

As a subsequent sensitivity, `python stage12/review/rank_bounds.py` restricts every predicted percentile to its individual-gene 0–100 range using clinical untreated profiles. First choose a common increment by bisection, clipping each incipient change to the gene's own feasible range and maintaining the original predicted panel average exactly. This clipped comparator gives gene MAEs of 5.556, 6.152 and 2.639, respectively. An unbounded uniform prediction exceeded the marginal range in 16 of 1,111 participant–gene combinations in Seoul and in one of 101 genes at each Leuven time. Next pair genes in the same atlas abundance stratum for which swapping predictions is marginally feasible in all 13 units. Greedily select disjoint pairs in ascending order of squared distance between untreated rank profiles. This pairs 90 genes and fixes 11. Under independent equiprobable exchanges in these 45 pairs, exact expected errors are 6.261, 6.815 and 3.362 versus the original 6.249, 6.536 and 3.299. The difference depends on comparator construction, especially in Seoul. These checks enforce marginal percentile bounds and preserve aggregate predictions, without constructing a joint library-wide ranking. To rebuild the clinical untreated ranks from original counts with pandas and SciPy, run `rebuild_bounds_input.py` using the release's stage5 files. The other calculations need only NumPy and the included control_ranks.tsv.
