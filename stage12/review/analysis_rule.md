# Does the assignment of changes to gene identities carry information?

This descriptive calibration uses the frozen state-only rank-change forecasts and observations for exactly the 101 previously fixed external ECM endpoints. The existing results for this panel had already been examined. Before this calculation, choose three comparators: zero change, the same predicted panel mean assigned to every target, and reassignments of the fixed predicted changes to other genes in the panel. The scalar comparator is a diagnostic in the scored feature space; it does not specify a cell simulator or full-rank transcriptome.

Compute (1) mean absolute gene error and (2) absolute error of the panel average, per participant (Seoul) or within-batch contrast (Leuven); then average equally over the 11 Seoul participants. In each random reassignment use the same gene-to-gene permutation for every participant and group. For the primary control reassign only within the previously defined ten deciles of untreated-atlas transcript counts in the 10,806-gene background, preserving each decile's distribution. Include an unrestricted reassignment as a sensitivity. Target genes tied on counts have the same decile. The mean of the panel and each forecast unit's spectrum of predicted values stay unchanged under reassignment; check this algebraically and numerically. There is no filtering by observed response. For the scalar comparator assign each unit's own predicted mean to all 101 targets.

For reassignments, report the exact expected mean absolute gene error as the average of the absolute errors of all allowable within-stratum forecast–measurement pairs, together with descriptive quantiles of 10,000 reassignments. These are controls over gene identity conditional on these data, neither patient significance tests nor biological replication. Report the fraction of draws at least as good as the original assignment; genetic pathway dependence may violate an exchangeable-label null. No parameters are fit to external measurements.
