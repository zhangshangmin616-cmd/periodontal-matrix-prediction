# Bounds on additive changes in percentile rank

This post hoc sensitivity analysis was prompted by inspection of the newly scored cross-laboratory forecasts. The primary check adds each model's rank change to the target's control percentile within each baseline library, clamps the resulting percentile to the interval [0, 100], and averages the resulting rank changes across baseline libraries. The full tissue atlas rule shifts an entire control profile in linear abundance before ranking. The atlas common-shift comparator assigns that library's mean target shift to each of its 101 targets. Hong Kong transfers assign source-derived shifts that are the same across all destination baseline libraries. A second calculation applies the bounds to the mean baseline rank and group-level prediction directly. Predictions and observed changes use the common 10,805-gene ranking background and the original 101 genes.

The table compares both aggregate and mean individual-gene error gains over zero for both clipping orders. Positive gain favours the forecast. This bounds check concerns numeric feasibility for each predicted rank. Clipping within the panel does not reconstruct a full transcriptome rank order. These descriptive calculations fit no parameters and add no participants. The script reads only the frozen expression and transfer files included in the previous and current releases.
