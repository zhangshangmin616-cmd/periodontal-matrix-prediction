# Independent reconstruction of gene-response transfer

`verify.py` reads the 10 author-deposited Hong Kong count columns, confirms the raw file hash and the complete library totals, redoes the Ensembl-to-HGNC mapping and compares the mapped counts with the archived matrix. The five source responses retain the ordering of the source donor codes. At the destinations it uses all 14 run count files, verifies their published MD5 values and sums technical runs belonging to a single Wuhan library. It constructs the fixed-share atlas multiplier from the untreated and tension-side cell-group counts. All percentile ranks use 10,805 genes, and each score uses all 101 targets. Running `python stage18/check/verify.py` after extracting the source archive reconstructs the three tables alongside this document. The program checks all 505 source-donor changes and all 1,212 destination gene records against the main analysis.

The orientation calculation enumerates signs for five paired source changes, always leaving destination data untouched. Exactly 16 of 32 patterns improve the panel score at each destination. Since the signed sets occur in opposite pairs, and the source panel shifts are small relative to these particular destination changes, this result largely reflects which sign matches the destination mean. At the individual-gene level none of the orientations beats zero at Wuhan 24 hours, four beat zero at Wuhan 48 hours, and twelve beat zero in the single 12-hour Zhejiang comparison. These assignments reuse the same five people and the same destination arms.

In the exploratory calculation keeping the source mean and average absolute gene deviation fixed, zero of 32 patterns beat zero-change gene error in either Wuhan contrast, and six did so in Zhejiang. Reversing donor signs can change gene order, direction and amplitude. Fixing one measure of spread does not isolate a biological mechanism. These orientation counts describe the tested source responses and are not sample-size estimates or significance tests.
