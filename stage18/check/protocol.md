# Independent reconstruction and orientation check

Recover the five donor-paired 12-hour responses from the authors' GSE173891 raw integer count table and HGNC identifier map. Retain the 10,805 genes available in Hong Kong from the fixed background, including all 101 targets. Independently read and combine the deposited Wuhan and Zhejiang counts at the GEO library level. Compute average-tie rank percentiles within each library before calculating the three contrasts: Wuhan 24 versus 0 hours, Wuhan 48 versus 0 hours, Zhejiang 12 hours versus unloaded. Compare unchanged source donor-mean shifts, source panel-mean shift, frozen atlas tissue model and zero. No treated destination expression enters these forecasts.

For the rank predictor only, also reverse the sign of each of the five paired Hong Kong changes in all 32 possible combinations. Score each unchanged vector against each destination. Report how many assignments have loss no greater than that of the correctly oriented vector on each endpoint, counting the genuine orientation and numerical ties. Also compare the correctly oriented five-donor transfer directly with its sign reversed. These are conditional orientation controls for five measured pairs. We did not randomise the biological signs, the normal and reversed signs need not be exchangeable, and these fractions are not population P values. No ordering is used to select a predictor. Readers can check every assignment.

After inspecting the unadjusted orientations, we added an exploratory control for cancellation. Sign changes can attenuate the donor mean as well as change its gene pattern. For each sign pattern we subtract its own gene mean, rescale the centred vector to the correctly oriented predictor's average absolute deviation across genes, and restore the correctly oriented predictor's mean. Scoring these alternatives keeps the panel prediction and one measure of gene spread fixed. Every transformation is constructed exclusively from Hong Kong data. Record their errors with the unadjusted controls and do not count the two analyses as separate evidence.
