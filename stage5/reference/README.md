# 人牙周膜受力图谱参考表达谱

参考数据来自 GEO GSE327337，包含一个未受力对照文库，以及受力第 3、7 天的压力侧和张力侧文库。输入保留第四阶段通过基础质控及 scDblFinder 的 62,490 个条形码，并沿用第四阶段独立计算的排他性标志分组。原研究公开的这五个文库没有可核实的逐细胞供者编号。[GEO](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE327337) · [原始论文](https://doi.org/10.1177/00220345261491310)

## 文件

- profiles.tsv.gz 保存 10,806 个可共同测量的基因，包含全部 101 个预设终点基因。每列名为“文库/标志群”。每个基因的计数除以该文库该标志群在**全部测量基因**上的总 UMI。文件只列出共同基因，因此每列和可以小于 1。
- groups.tsv 包含捕获的条形码数量、全部基因 UMI、共同背景 UMI、文库内总 UMI 份额（rna_weight）和条形码数份额（cell_fraction）。这些份额来自捕获并通过筛选的材料，测序捕获效率、细胞解离和筛选均可能影响份额与组织真实组成的关系。
- features.tsv 为与表达谱同序的基因及上一阶段的 ECM 分组。outside_ecm 表示未列入上一阶段 217 基因的可测 ECM 集合。
- input/ 保存从第四阶段取出的按文库和标志群计数、基因归属、分析设置和 GEO 来源清单，供离线复算。reference_manifest.json 提供输入及主要输出文件的 SHA-256。
- reference_reconstruction.tsv 校验六类参考谱按 RNA 份额求和时能否还原同一文库的全体入选条形码。original_check.tsv 另行从提交者的五个稀疏计数矩阵重算。

成纤维样、血管壁样、免疫样、内皮样、神经胶质样五个命名标志群在每个文库均有至少 30 个入选条形码。残余类汇总上皮样、红系样、未分类、歧义四组的原始整数计数及全部 UMI，再计算表达谱。六组互斥并覆盖全部入选条形码。残余类贡献各库约 28% 至 35% 的捕获 RNA。类别内部的混合成分变化、测序条件和分类误差都可能使参考谱变化，尤其影响残余类。正畸图谱的成纤维样标志类别与健康人图谱的作者标注牙周膜间充质类别存在差异。

## 复算

在本目录运行 `python build_reference.py`。依赖为 NumPy 与 pandas。各文库的复合表达为各标志群的基因分子份额乘以该群在文库中的总 UMI 份额，再对各群求和。直接用条形码计数份额作权重会改变模型的估计对象。

如已按第四阶段说明取得 GEO 15 个矩阵组件与该阶段的逐条形码判定表，可运行 `python check_original.py 第四阶段工作目录` 独立核对。该命令额外依赖 SciPy，逐文库读取原始提交文件。它直接比较整数计数、所有特征的总 UMI 和全体入选条形码的基因分子份额，保留所有五个文库的结果。
