# Untreated tissue variability in the Leuven study

The primary calibration uses only the 22 untreated tissue specimens from the sequencing batch that also contained day-28 samples. It compares two disjoint groups of untreated tissue specimens using the day-7 jaw proportions. Its 7,920 assignments recycle those same specimens. They measure variability under this construction. The proportions are descriptive and do not supply patient-level significance or a treatment-effect interval.

The true day-7 shift was +0.629 percentile points in the panel mean. Absolute control-only differences had a median of 0.319 and 1,411 of the 7,920 (17.8%) were at least 0.629. The central 95% of signed control-only shifts spanned −0.836 to +0.948. With equal weight per jaw in each arm, the day-7 shift was +0.448, reached in absolute value by 35.0% of the similarly standardised untreated contrasts. In a separate descriptive check of the five untreated tissue specimens from the day-7 sequencing batch, three of six small equal-jaw control contrasts reached 0.448. Day-7 within-jaw relabelling of all 24 exposed and control specimens is reported separately in the output.

Run `python stage13/calibration/score.py` and `python stage13/calibration/check.py` with Python and NumPy. From the included 63 archived count files the scorer recomputes all sample scores anew and confirms the historical ranks. The scalar checker uses a separate implementation to verify the observed shift and the primary 7,920-assignment result. `archived_scores.tsv` reproduces the earlier stage5/results/external_sample_scores.tsv. Each comparison and reference value has its own row in `calibration.tsv`. The arrays in `distributions.npz` hold every signed assignment value for each comparison.
