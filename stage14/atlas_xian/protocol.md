# Test of frozen atlas forecasts against the Xi'an six-hour culture

The Xi'an culture-to-culture contrasts had already been examined. Before calculating atlas scores, choose exactly the day-3 tension-side fibroblast and fixed cell-group RNA-share tissue multipliers used in the stage 13 Hong Kong experiment, with zero change as reference. Apply their full published values with no fitting, frequency scaling or duration correction. Assess every frozen target (101) on the common mapped background (10,805). Both frequencies come from one study and share three 0 Hz reference libraries.

Use log2(1 + full-library CPM) per run. For each gene, observed change is the loaded group mean minus the control group mean on the transformed scale. Predictions are the frozen log2 shifts. On the rank scale, apply each multiplier to the CPM profile of each untreated run and re-rank all background genes within that run with average ties and range 0–100. Average the predicted change across the three controls. Observed rank changes are differences of mean within-run ranks between arms. No loaded measurements enter a prediction. The primary score is mean absolute error across the 101 gene changes. Also report absolute error in the panel mean. Recalculate both endpoints after dropping any one control or loaded run from the relevant contrast, recomputing predicted rank means if a control is removed. These descriptive deletions do not estimate donor uncertainty. No donor pairing is assumed.
