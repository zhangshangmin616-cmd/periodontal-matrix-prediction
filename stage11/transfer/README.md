# Leuven time transfer

The scalar 0.23238716799216566 was learned by least squares through the origin from 10,705 genes outside the target panel in the Nanjing atlas. It describes attenuation of a source-model directional force contrast from day 3 to day 7. We tested that numerical coefficient on the day-7 and day-28 tissue-level loaded-versus-control contrasts of the Leuven cohort. This involves different time intervals, different loading conditions, and a different expression contrast. The method uses *measured* Leuven day-7 expression. It predicts the later response from an earlier measurement and does not forecast from an untreated sample alone. The time groups have their own controls. Repeated specimens from individual donors cannot be identified from the public metadata.

## Retrospective analysis rule

Before computing these new errors we fixed protocol.txt, SHA-256 ce4624f2783c63d3bce00cb4dee1360aa7966616a4702903d829ee399cc5f273. The past study had already examined this cohort. The frozen rule and local fingerprint document the sequence of this analysis. Day 7 comprises 19 exposed and five control specimens in archive batch 4. Day 28 comprises 17 exposed and 22 controls in archive batch 3. Counts are from the public NCBI processing pipeline, normalised using all counts of each run. The 10,806-gene expression background contains the 101 fixed ECM genes. Each gene receives equal weight. The primary group summary is the arithmetic mean over specimens of log₂(CPM + 1). The alternative is log₂ of the group mean CPM plus one, i.e. log₂(mean CPM + 1).

Values are mean absolute errors in log₂ expression units. For the primary 101-gene endpoint the reduction in error relative to no change was 0.019891, and the reduction relative to one-quarter persistence was 0.001569. No change had the lowest error across all 10,806 genes under both conventions. The difference from generic attenuation is small in these measurements and does not establish a tissue-invariant mechanism.

After the initial comparison we repeated the 101-gene calculation, first leaving out one specimen at a time, then separately giving the two arches equal weight within each time and treatment group. In all 63 leave-one-out comparisons under the primary scale the fitted coefficient outperformed zero and one quarter. The improvement over one quarter varied from 0.00055 to 0.00374. Under the second scale it beat one quarter in 62 of the 63. Equal-arch weighting retained a positive improvement over one quarter on both scales. These overlapping deletions describe sensitivity and cannot be counted as independent replication.

## Offline reproduction

Run `python score.py`, `python sensitivity.py`, and `python check.py` in this directory with Python and NumPy. The input is specimen_cpm.npz, with 63 whole-library-normalised CPM vectors, the ordered dataset-run keys and the 101-gene mask. specimen_metadata.tsv links each run to a BioSample identifier, time, control, arch and batch. gene_contrasts.tsv.gz contains the four measures per gene. scores.tsv includes all methods and subsamples. sensitivity.tsv documents each post hoc deletion and jaw weighting. check.py independently rebuilds the gene contrasts and all 20 errors from the specimen inputs.

For rebuilding the CPM file from source counts, place stage 5 research package contents in work/stage5 and this directory in work/stage11/transfer. Run `python rebuild.py` with NumPy, pandas and SciPy. The local SRA inputs, accession and publicly documented count pipeline are in the stage 5 archive. The source coefficient is independently generated by stage11/external/atlas_persistence.py from the stage 8 atlas file.
